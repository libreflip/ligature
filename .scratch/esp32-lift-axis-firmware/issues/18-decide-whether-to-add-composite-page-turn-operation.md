# Decide whether to add a composite page-turn operation

Type: grilling
Status: unclaimed
Blocked by: 11

## Question

After defining a complete production host protocol that works without `G73` or a `Turning` state, should Ligature add a composite page-turn operation at all? If so, define its ownership boundary, phases, parameters, state reporting, blower-threshold events, cancellation semantics, and conformance tests without making the ordinary host-sequenced commands incomplete or dependent on it.
